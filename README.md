# Практическая работа: борьба с дисбалансом классов

## Вариант C

### Цель работы

Исследовать задачу бинарной классификации с сильным дисбалансом классов и сравнить несколько методов его устранения:

- Baseline-модель без коррекции дисбаланса;
- `class_weight="balanced"`;
- Undersampling;
- SMOTE.

Также необходимо определить, какой метод показывает лучший результат, и проверить стабильность результатов с помощью одинаковой схемы кросс-валидации.

---

## 1. Создание датасета

Для эксперимента был создан искусственный бинарный датасет с помощью `make_classification` из библиотеки Scikit-learn.

Параметры датасета:

- количество объектов: 2000;
- количество признаков: 10;
- количество классов: 2;
- соотношение классов: примерно 95% / 5%;
- `random_state = 42`.

Таким образом, соотношение классов составляет примерно 19:1, что соответствует условию сильного дисбаланса.

---

## 2. Базовая модель

В качестве базовой модели использовалась `LogisticRegression` без какой-либо коррекции дисбаланса.

Baseline необходим для того, чтобы получить точку отсчёта и сравнить с ней результаты других методов.

Для оценки использовались следующие метрики:

- Accuracy;
- Precision;
- Recall;
- F1-score.

Для задачи с сильным дисбалансом особое внимание уделяется Recall и F1-score, поскольку одной Accuracy недостаточно для объективной оценки качества модели.

---

## 3. Методы борьбы с дисбалансом

### 3.1 Class Weight

Использовался параметр:

```python
class_weight="balanced"
```

Модель автоматически увеличивает вес редкого класса во время обучения.

Преимущество метода заключается в том, что исходные данные не удаляются и новые объекты не создаются.

---

### 3.2 Undersampling

При Undersampling уменьшается количество объектов преобладающего класса.

В результате обучающая выборка становится более сбалансированной.

Недостаток метода — часть исходных данных удаляется.

Для реализации использовался:

```python
RandomUnderSampler
```

---

### 3.3 SMOTE

SMOTE — метод искусственного увеличения количества объектов редкого класса.

Вместо простого копирования существующих объектов создаются новые синтетические примеры на основе существующих объектов minority class.

Для реализации использовался:

```python
SMOTE
```

## 5. Cross-Validation

Чтобы убедиться, что результат не зависит только от случайного разбиения данных, была использована Stratified 5-Fold Cross-Validation.

Для всех методов использовалась одинаковая схема:

```python
StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)
```

Основной метрикой для сравнения был выбран F1-score.

Результаты:

| Метод | Mean F1 | Std |
|---|---:|---:|
| Baseline | — | — |
| Class Weight | — | — |
| Undersampling | — | — |
| SMOTE | — | — |

`Mean F1` показывает среднее качество модели на пяти разбиениях.

`Std` показывает разброс результатов между разбиениями. Чем меньше стандартное отклонение при сопоставимом качестве, тем стабильнее результат.

## 6. Итоговый анализ

По результатам эксперимента методы коррекции дисбаланса были сравнены с базовой Logistic Regression.

При анализе учитывался прежде всего F1-score, поскольку датасет имеет сильный дисбаланс классов.

Лучший метод определяется по максимальному среднему F1-score в рамках 5-Fold Cross-Validation.

Использование одинаковой схемы валидации для всех моделей позволяет корректно сравнить методы и уменьшить влияние случайности разбиения данных.
